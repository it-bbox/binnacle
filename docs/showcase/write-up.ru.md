# Сколько стоила работа над самим Binnacle

_English version: [write-up.md](write-up.md). Этот файл — русский дубликат; обновляется вместе с `write-up.md`._

Binnacle создавался теми же агентами, для которых он и сделан, и записывал расход токенов в сессиях, где шла работа. Этот текст читает эти записи обратно: сколько стоила работа и куда ушли токены.

Здесь только сводные агрегаты. Ни один тикет, задача или сессия не назван, а каждая цифра — то, как сам Binnacle прочитал свои данные об использовании на **31 октября 2026 года**.

## Как читать цифры

- **Запись — это один вызов, учтённый один раз.** Когда файл сессии harness и его экспорт OpenTelemetry сообщают об одном и том же вызове, Binnacle хранит одну запись о нём.
- **Виды токенов никогда не складываются.** Входные из кэша — это контекст, который провайдер перечитал из своего кэша; рассуждения — часть выходных, в которой модель думала. Они показаны рядом, как их показывает Binnacle.
- **Неполный счётчик — не полный итог.** Некоторые harness сообщают только часть видов токенов. Отсутствующие Binnacle называет «нет данных», никогда не нулём, поэтому сумма по такому счётчику — нижняя граница.
- **Расчётные чтения помечены.** Каждая сумма, среднее и доля ниже — расчёт Binnacle по сохранённым записям; сами счётчики токенов — то, что сообщил каждый harness.

## Куда ушли токены, по ролям

## Сколько стоила одна завершённая задача

- **200 завершённых задач** имеют отнесённые к ним запуски; **ещё 50** завершены без запуска, который Binnacle мог бы к ним отнести.
- **В среднем на завершённую задачу, расчёт по этим 200:** 79,6 записи, 2 587 входных, 11 934 411 входных из кэша, 261 980 записей в кэш, 54 354 выходных токена и 17 861 токен рассуждений.
- **В среднем запусков на задачу, расчёт:** 4,2, из них 3,3 — запуски субагентов.
- **Доля доработки, расчёт:** 30,5% — токены доработки, делённые на токены реализации и доработки вместе, в среднем по завершённым задачам.
- **Приёмка с первого прохода, расчёт:** 8,0% — доля прошедших ревью завершённых задач, которым доработка не понадобилась вовсе.

## Метод

Всё здесь прочитано из собственного хранилища Binnacle 31 октября 2026 года. Итоги, разбивка по ролям, недельные итоги и расчётные чтения совпадают с `usage_get` на эту дату; разбивка по моделям прочитана из тех же сохранённых записей и посчитана так же, потому что `usage_get` по моделям не группирует. Цифры — одно чтение, снятое в один момент; Binnacle продолжает записывать, пока работает, поэтому более поздний вызов увидит ещё несколько записей. Binnacle хранит токены, но никогда — стоимость или цену. Расчётное чтение помечено, а пробел в отчётности назван «нет данных», никогда не нулём.
