This skill needs no daemon to be started and no `binnacle` MCP server: it runs the CLI command `binn dashboard` in this harness's shell. The daemon serves the dashboard, so it fails while the daemon is stopped, and says so.

The dashboard's token authorises the daemon's local API, and this shell's output reaches the model's provider and the session's transcript (ADR-0031). So `binn dashboard` hands the token to the browser itself, which opens already authorised, and prints the address alone, which carries no token: nothing in it was masked, cut or hidden, and nothing is missing from it. Never run `binn dashboard --print`, which prints the token, and never show, read or ask for the token in any other way.

Give the human each command you offer them alone in a fenced block, which copies in one click: a skill such as `/binnacle:daemon start` in a plain fence, a shell command such as `binn daemon start` in a `bash` fence.

1. Run `binn dashboard` once, with no option.
   - If the shell cannot find `binn` (`command not found`, exit 127), stop. Say that `binn` is not on this harness's PATH, and point to the README's setup section (*Install*).
   - Exit 4 means the daemon is not running. Stop, quote what it printed, and name `/binnacle:daemon start`, or `binn daemon start` at a terminal, then `/binnacle:dashboard` again.
   - Any other non-zero exit means the dashboard could not be opened. Stop, give the exit code and quote what it printed on stderr.
2. Show the address it printed on stdout, whether or not a browser opened.
3. If it printed on stderr that it could not open a browser, quote that line, say that no browser opened, and say: run `binn dashboard --print` at a terminal and open what it prints there, without pasting it into the chat. Otherwise answer that the dashboard opened in the browser at that address, and that if no browser appeared, run `binn dashboard --print` at a terminal and open what it prints there, without pasting it into the chat.

Never say that a token was masked or hidden, and never ask the human to copy an address from `binn dashboard`'s output in step 1: the browser already has what it needs. Run no other command, and change nothing.
